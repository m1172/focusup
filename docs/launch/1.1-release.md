# Vaqtim 1.1.0: Pro, Family and widgets

Branch `release/1.1-all-features`. Everything is switched on in code:

- `PRO_ENABLED`, `FAMILY_ENABLED` and `WIDGETS_ENABLED`.
- The widget and monitoring-tool plugins.
- Version 1.1.0, build 10 on both platforms, with runtime `1.1.0-pro-family`.

`npm run release:check` stops the build until the RevenueCat keys are in `.env.production`, so nothing can ship half-set-up.

**Who does it:**
- **Owner**: you. These steps involve consoles, money, legal text or production.
- **Claude**: can do it once you give the go-ahead.

Wait until **1.0.0 (build 9) is approved** before you submit anything new to Apple. A new build sent now would replace the one in review.

## 1. Stores and RevenueCat (owner)

1. App Store Connect → Vaqtim → Monetization → Subscriptions:
   - Create one group with `focusup_pro_monthly` ($1.99), `focusup_pro_annual` ($14.99), `focusup_family_monthly` ($3.99) and `focusup_family_annual` ($29.99).
   - Rank Family above Pro, and leave Family Sharing off.
   - Add en and ru names, plus a review screenshot of the paywall.
2. Play Console → Monetize → Subscriptions:
   - Create `focusup_pro` and `focusup_family`, each with `monthly` and `annual` base plans.
   - Turn on Uzbekistan pricing.
3. RevenueCat:
   - Create one project with both apps and import the 6 products.
   - Set up the entitlements `pro` (all products) and `family` (Family products only).
   - Set up the offerings `default` (Pro) and `family` (Family), each with `$rc_monthly` and `$rc_annual`.
   - Set restore behaviour to "Keep with original App User ID".
   - Connect Apple server notifications and Google real-time notifications.
4. Put the two **public** keys into `.env.production`:
   - `EXPO_PUBLIC_REVENUECAT_IOS_API_KEY`, which starts with `appl_`.
   - `EXPO_PUBLIC_REVENUECAT_ANDROID_API_KEY`, which starts with `goog_`.

   Never use the `sk_` secret key here. Don't paste either key into a chat; edit the file yourself.

Business agreements, tax and bank details are already accepted. Leave the Business section as it is.

## 2. Server (owner's OK, then Claude)

1. Set the Edge Function secrets yourself in the Supabase dashboard:
   - `REVENUECAT_SECRET_KEY`, the `sk_` key.
   - `REVENUECAT_WEBHOOK_SECRET`, a random value of 32 or more characters.
   - `REVENUECAT_ENVIRONMENT=PRODUCTION`.
   - `FAMILY_COUNTRIES=UZ`.
2. In RevenueCat, point the webhook at `…/functions/v1/focusup-api/v1/webhooks/revenuecat` with `Authorization: Bearer <webhook secret>`.
3. Apply the production migrations: `202611080001_family.sql`, `202611090001_family_usage.sql` and `202611090002_billing.sql`.
4. Deploy `focusup-api` using the command in AGENTS.md section 7.
5. Set `FAMILY_ENROLLMENT_ENABLED=true` only after the device tests in step 4 pass.

## 3. Legal and declarations (owner)

1. Have the Family consent text (`family.parent.consentBody`) checked against Uzbekistan's personal-data law (lex.uz 4396428), including where data must be stored.
2. App Store:
   - Update the privacy labels for purchases and child usage minutes.
   - Update the age rating answers.
   - Mention Family in the review notes.
3. Google Play:
   - Update Data safety.
   - Update the Accessibility declaration and its video to show family use.
   - Declare the monitoring tool and check the Families policy.
4. Review the updated App Store listing text in `store.config.json`, which now has an "Optional subscriptions" section. Use the same wording for the Play listing.
5. Update the website where it says "Free" to say it is free to use with optional subscriptions. The website deploy needs your OK.

## 4. Test builds (Claude builds, owner tests on real phones)

The simulator has no Screen Time, so these tests need real iPhones and Android phones.

1. Claude makes build 10 for TestFlight and Play internal testing.
2. Owner tests purchases with sandbox and licence testers:
   - Buy, restore and cancel each of the 4 plans.
   - Upgrade from Pro to Family.
   - Check that an account subscribed on one store can't buy again on the other.
3. Owner tests Family with every parent/child pairing (iPhone→iPhone, iPhone→Android, Android→iPhone, Android→Android):
   - Pairing works, rules apply, a daily limit stops a session, and the usage numbers appear.
   - Removing a child phone works.
   - A fourth child is refused.
4. Owner tests widgets: add the widget on iPhone and Android, and check that tapping it opens the right app in Vaqtim.
5. Check that the "Vaqtim features" page in the app is true for each line. Change any feature that isn't ready to "experimental" or "not available".

## 5. Release (owner's go)

1. Submit 1.1.0 to App Review with the four subscriptions attached.
2. Promote the Play build to production.
3. Watch RevenueCat webhook deliveries, purchase errors and restore reports for the first days.
